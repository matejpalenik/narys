# Storybook canvas assets

| Files | Source |
|---|---|
| `semantic/*.svg` | [Carbon icons 11.92.0](https://www.npmjs.com/package/@carbon/icons/v/11.92.0), 32 px SVG files. `shopping-cart.svg` maps to `shopping--cart.svg`. The remaining filenames match the originals. |
| `technology/*.svg` | [Devicon 2.18.0](https://github.com/devicons/devicon/tree/v2.18.0), original SVG variants. `aws.svg` is the Amazon Web Services original. Technology names and logos identify their respective projects. |
| `font/ibm-plex-sans-latin.woff2` | [Fontsource IBM Plex Sans variable 5.3.0](https://www.npmjs.com/package/@fontsource-variable/ibm-plex-sans/v/5.3.0), upright Latin WOFF2. |

Each directory contains the license supplied with its source distribution. The preview serves these files locally.
